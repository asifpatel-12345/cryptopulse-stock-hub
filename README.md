# CryptoPulse & Stock Hub 🚀📈

A high-performance, dark glassmorphic real-time financial tracking and trading dashboard built with **HTML5, CSS3, and Vanilla JavaScript**.

## ✨ Features
* **Live Ticker Marquee:** Continuous scrolling real-time price feed for top cryptocurrencies and global tech stocks.
* **Interactive HTML5 Canvas Price Chart:** Dynamic candlestick-style rendering supporting multiple timeframes (`1H`, `1D`, `1W`, `1M`, `1Y`).
* **Real-Time Price Simulation Engine:** Prices fluctuate dynamically every 2 seconds with automatic color-coded gain/loss indicators.
* **Advanced Trading Terminal:** Simulated buy/sell orders, live order book depths, and automated portfolio P&L calculation.
* **AI Sentiment Gauge:** Visual market greed & fear score calculation with macro sentiment breakdowns.
* **Responsive Glassmorphism UI:** Modern dark/light mode toggle with frosted glass aesthetics.

## 🛠️ Tech Stack
* **Markup:** HTML5
* **Styling:** CSS3 (Flexbox, Grid, CSS Variables, Glassmorphism)
* **Logic:** Vanilla JavaScript (ES6+, HTML5 Canvas API)
* **Icons & Fonts:** FontAwesome 6, Google Fonts (`Outfit`, `JetBrains Mono`)

## 🚀 Getting Started & GitHub Upload
1. Clone or download this repository.
2. Ensure all 4 files (`index.html`, `style.css`, `script.js`, `README.md`) are in the same folder.
3. Open `index.html` in any modern web browser or deploy directly to GitHub Pages!
